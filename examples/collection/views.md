# Choose a useful view

Use the smallest view that explains the point. You do not need every kind of visual in every write-up.

| The question | A useful view |
| --- | --- |
| What happens first? | A call tree |
| What changes? | A diff |
| Who passes information to whom? | A diagram |
| How do two choices compare? | A short table |

```mermaid
flowchart LR
  A[Find the answer] --> B[Choose a view]
  B --> C[Check that it helps]
```

Wide diagrams scroll on a phone rather than making their labels tiny.
