# Share and keep the source

A collection has one main link. Each page also has its own link, which stays the same when that page is edited or moved in the list.

## Keep a copy

Keep the source files on disk. The collection and all its pages share one expiry date, about 30 days after creation. Editing a page does not restart the clock.

{% callout title="Unlisted is not private" tone="warning" %}
Anyone who gets the link can read the pages. Search engines are asked not to index them. Keep credentials and personal data out.
{% /callout %}
